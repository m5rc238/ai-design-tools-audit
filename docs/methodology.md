# Methodology

## Scope

This project evaluates AI design and UX research tools for transparency, workflow defensibility, and likely differentiation surface.

## Principles

- Evidence first: no scoring without source-backed observations
- Conservative inference: unknown stays unknown
- Reproducibility: scoring logic and schema are public
- Separation of facts and interpretation: raw evidence is logged before conclusions

## Process

1. Gather source evidence (product docs, official pages, demos, release notes).
2. Record factual observations in an audit file.
3. Map observations to schema fields in `SCHEMA.md`.
4. Assign rubric scores using `docs/rubric.md`.
5. Add summary deltas to `docs/summary.md`.

## Evidence Standards

- Prefer first-party documentation and product behavior
- Mark confidence as High, Medium, or Low
- Use direct quotes sparingly and include URLs
- Flag unresolved assumptions explicitly
