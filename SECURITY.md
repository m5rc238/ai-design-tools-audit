# Security Policy

## Reporting a Vulnerability

If you find a security issue related to repository infrastructure or published artifacts, open a private report through GitHub Security Advisories if enabled, or contact the maintainer directly.

Please include:

- Description of the issue
- Steps to reproduce
- Impact assessment
- Suggested remediation (if known)

## Scope

This repository is primarily research content. Most risks are expected to involve supply chain, workflow automation, or publishing pipeline configuration.
