# Contributing

Thanks for contributing to AI Design Tools Audit.

## Quick Start

1. Open an issue to propose a new tool audit or rubric change.
2. Create a branch from `main`.
3. Use `templates/audit-template.md` to draft the audit.
4. Include source links for every major claim.
5. Open a pull request with a concise summary.

## Contribution Standards

- Evidence-backed claims only
- Explicit confidence labels for uncertain evidence
- Keep facts and interpretation separated
- Keep edits small and reviewable when possible

## Pull Request Checklist

- [ ] Audit includes source URLs
- [ ] Schema fields map to `SCHEMA.md`
- [ ] Summary table updated if score-impacting
- [ ] No sensitive/private data added
